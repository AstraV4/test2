# MèmeDex 🃏

Jeu de cartes à collectionner basé sur les mèmes et la culture internet française.
Un seul fichier `index.html` — aucune installation, aucune dépendance à compiler.

- 74 cartes (vraies photos Wikimedia + refs stylisées)
- Ouverture de boosters en carrousel, 6 raretés + variante Shiny ✨
- 10 boosters gratuits/jour + 1 toutes les 10 min
- Progression sauvegardée dans le navigateur (localStorage)

---

## 🚀 Mettre en ligne (le plus simple : GitHub Pages — gratuit)

1. Va sur **github.com** → bouton **New** pour créer un dépôt (repository).
   - Nom : `memedex` (ou ce que tu veux)
   - Coche **Public**
   - Clique **Create repository**
2. Sur la page du dépôt → **Add file → Upload files**.
   - Glisse `index.html` (et ce `README.md` si tu veux).
   - Clique **Commit changes**.
3. **Settings** (onglet en haut) → **Pages** (menu de gauche).
   - **Source** : `Deploy from a branch`
   - **Branch** : `main` + dossier `/ (root)` → **Save**.
4. Attends ~1 minute, rafraîchis la page **Pages** : ton lien public apparaît, du type :
   **https://TON-PSEUDO.github.io/memedex/**

👉 Ce lien s'ouvre sur n'importe quel téléphone/PC, avec **les vraies photos qui s'affichent**.
Partage-le à tes potes, ils pourront jouer chacun de leur côté.

> Astuce : pour mettre à jour le jeu plus tard, réuploade simplement un nouveau `index.html`
> (Add file → Upload files → Commit). Le lien reste le même.
